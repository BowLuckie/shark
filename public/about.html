About

A small wrapper around a Unity WebGL game, plus a save manager.

About Shrek: My Neighbor

Shrek: My Neighbor is a free game by the Russian studio Anegelator Games. It is one of several Shrek spinoffs they have made, and they play much alike. The mechanics and the antagonist are modelled on the 2017 indie game Hello Neighbor.

How to play

Shrek has captured your dog. You climb through his treehouse mansion, which is full of traps and puzzles, collecting the items you need to get further. Free the dog and escape town.

Movement is WASD. The other controls are:

  • E interact
  • F secondary interaction
  • G drop item
  • R swap items
  • Space jump
  • C crouch

A legend at the bottom of the screen shows the controls at all times.

About Shark Launcher and save manager

The original page for this game was built for an ad-supported portal and depended on that portal's SDK. This is a stripped-down replacement for that page. It loads the same game, answers the SDK calls locally, and leaves out the ad popup.

What it does

  • Loads the game builds from a CDN, pinned to one commit so the files never change under it.
  • Provides a local stand-in for the platform SDK, so the game starts without the portal.
  • Removes the page's ad overlay, and sets the game's own ad-free flag in your save on load.
  • Includes a save manager for named slots, import, export and editing.

What it doesn't do

  • It does not host the game. No game files are in this repository.
  • It does not change the game's code or assets. Everything in-game is as the developer made it.
  • There is no cloud sync, account or leaderboard. Those calls are answered with empty results.

Where your save is

In your browser's localStorage, for this site only. It is not uploaded anywhere. Each visitor has their own, and there is nothing shared.

Clearing site data for this domain deletes it, and so does a private window closing. The save manager's export button writes a file you can keep. That file is the only real backup.

be warned that the "slots" provided by the save editor store a save file as it was at one point in time so if you are juggling multiple saves, you will have to frequently refresh and reload edits, and keep and maintain backups as you play.
